# Orichan Start LP

React + TypeScript + Tailwind CSS landing page for Vercel.

## Vercel

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

## Environment Variables

Set this in Vercel when GA4 tracking is needed.

```bash
NEXT_PUBLIC_GA_ID=G-D5DS1G481P
```

If `NEXT_PUBLIC_GA_ID` is not set, GA4 is skipped without errors.
